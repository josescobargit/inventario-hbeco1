# Devoluciones y documentos relacionados

Una devolución nunca puede superar lo despachado menos devoluciones anteriores. Toda unidad que regresa aumenta el stock físico; solo las aprobadas para bodega o piso quedan disponibles. Bloqueadas, dañadas, en revisión o no utilizables aumentan también el saldo bloqueado y abren una incidencia.

Las notas de crédito y débito se asocian a la factura y no cambian sus estados operativos. El valor neto se calcula como valor de factura menos NC más ND.
